# Данные Hidden Pairs

Скачать CSV со [страницы соревнования](https://www.kaggle.com/competitions/week-03-hidden-pairs/data) и положить в эту папку.

| Файл | Содержимое |
| --- | --- |
| `train.csv` | 2 520 строк с метками для обучения |
| `validation.csv` | 560 строк с метками для оценки |
| `test.csv` | 1 116 строк без меток |
| `sample_submission.csv` | Шаблон ответа `row_id,target` |

Каждая строка содержит 512 признаков `f0000`–`f0511`. `row_id` нужен для сопоставления предсказаний и в признаки не входит. Validation с train не объединять. Конкурсные CSV в Git не включены.
