# Финальное решение SBMTeam

Здесь собран воспроизводимый конвейер с фиксированными параметрами и seed `1027309`. Он обучает две финальные модели, сравнивает их с базовыми решениями и создаёт submission из исходных конкурсных CSV.

## Файлы

- `final_submission_notebook.ipynb` — пошаговый запуск и сравнение 10 моделей.
- `final_model_runner.py` — тот же конвейер для запуска из терминала.
- `svc_experiments.py` — преобразования и дополнительные признаки.
- `svc_multikernel_experiments.py` — блоки признаков и RBF-ядра.
- `svc_final_rescue_experiments.py` — whitening и компоненты ансамблей.
- `requirements.txt` — зафиксированные версии библиотек финального запуска.

Исходные данные лежат в `../data/`. Инструкция запуска — в [корневом README](../README.md#воспроизведение), история поиска решения — в [docs/experiments.md](../docs/experiments.md).

## Выходные файлы

- `final_submission.csv` — основной результат NEW5.
- `submission_NEW5_sqrt_s100_aux20.csv` — те же предсказания с конкурсным именем.
- `submission_rescue_corrected_best.csv` — второй финальный вариант, Rescue T6.

При запуске по инструкции и из ноутбука файлы сохраняются в `../submissions/`. Код проверяет порядок `row_id`, конечность score и диапазон `[0, 1]`. Обучение идёт на CPU; готовые модели и локальные кеши не требуются.

Для интерактивного запуска установить Jupyter (`uv pip install jupyter`), открыть ноутбук и выполнить **Restart and Run All**.
